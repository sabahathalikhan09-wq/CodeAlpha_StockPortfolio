
# CodeAlpha Stock Portfolio Tracker

## Description
A simple stock portfolio tracker developed using Python as part of the CodeAlpha Python Programming Internship.

## Features
- Uses a predefined stock-price dictionary
- Accepts stock symbols from the user
- Accepts the quantity of each stock
- Calculates the investment value
- Calculates the total investment

## Concepts Used
- Python
- Dictionary
- User input
- If-else statements
- For loop
- Arithmetic operations
